Before you start

What you'll need for each check

Sensor check

Connect the Arduino to collect Heart Rate, Temperature in °C and SpO₂ automatically, then run the fusion analysis.

Manual check

Enter Heart Rate (bpm), Temperature (°C) and SpO₂ (%), then upload a raw ECG signal file for analysis.

ECG signal file

Use a raw ECG signal file in CSV, TXT or DAT format with numeric values. Clinical/tabular CSV files should not be uploaded as ECG signals.

FAQ

Common questions

Is CardioAlert a real diagnostic tool?

No. This application demonstrates a fusion deep learning system for heart-health analysis. Its output is not a medical diagnosis. Consult a qualified healthcare professional for medical concerns.

What data does the model use?

The clinical/vitals branch uses three features: Heart Rate, Temperature in Celsius and SpO₂. These features are combined with ECG signal features by the fusion model.

What's the difference between Sensor Assessment and Manual Entry?

The sensor page collects the three vital readings automatically from the connected device. The manual page lets you provide the same values yourself. Both can be combined with an ECG signal for fusion analysis.

What format should my ECG file be in?

Upload a CSV, TXT or DAT file containing raw numeric ECG signal values separated by commas or new lines. The backend uses 250 Hz as the default sampling rate unless another sampling rate is provided.

Can I see my past checks?

Yes. Completed checks are stored in your account and displayed under Recent checks on the dashboard.

Is my data private?

Account information and check history are stored within the application database. Avoid entering sensitive real-world medical information when using the system for demonstration or academic purposes.
